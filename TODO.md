# ODIY AI delivery checklist

## Premium English-first dashboard
- [ ] The product presents a premium, clean and modern dashboard with a white/light-gray background and purple/blue accents.
- [ ] The experience is professional and adult-oriented: no anime and no childish design.
- [ ] Desktop and mobile layouts remain usable, readable and responsive.
- [ ] Smooth, restrained animations and clear interaction states support a professional UX.

## IELTS practice and mock exams
- [ ] Complete IELTS Reading, Listening, Writing and Speaking practice is available.
- [ ] Reading includes a passage and questions with answer submission.
- [ ] Listening includes playable browser audio, questions and transcript-friendly practice.
- [ ] Writing includes Task 2 drafting, word count and AI feedback handoff.
- [ ] Speaking includes microphone speech-to-text where supported plus typed fallback and feedback handoff.
- [ ] Mock exam flow includes a timer and a results/progress path.

## AI tutor and learning tools
- [ ] AI English Tutor provides real model-backed feedback when an OpenAI-compatible key is configured.
- [ ] The tutor remains usable in previews through a meaningful local fallback when no model key is configured.
- [ ] Grammar and vocabulary learning remain functional with explanations, pronunciation and progress updates.

## Progress and production readiness
- [ ] User progress, statistics and estimated IELTS Band Score are visible and update from practice actions.
- [ ] Existing local persistence is preserved through localStorage.
- [ ] The app builds cleanly with the repository TypeScript/Vite toolchain.
- [ ] The existing GitHub repository is modified in place; no separate project is created.
